Sou **Desenvolvedor de Software**, com foco em desenvolvimento Back-end e experiência prática na construção de aplicações e sistemas voltados à resolução de problemas reais.

## 🚀 Projetos em destaque

### 🩺 [Triagem-ADH](https://github.com/Nuillexe/adh-triagem)

Sistema de gestão e relatórios desenvolvido para a Associação de Diabéticos e Hipertensos de Vitória da Conquista (ADH). A aplicação permite cadastrar participantes, registrar medições de glicemia e pressão arterial, organizar informações e gerar relatórios, auxiliando a associação no acompanhamento dos atendimentos realizados durante seus eventos.

**Tecnologias:** Python, Django, PostgreSQL, HTML, CSS e Bootstrap.

### 📚 [LibQueue](https://github.com/Nuillexe/school-library-manager)

Sistema de gerenciamento de biblioteca desenvolvido em Java e JavaFX, inicialmente como projeto acadêmico e posteriormente expandido como projeto pessoal. A aplicação utiliza conceitos de Programação Orientada a Objetos, Estruturas de Dados, filas de prioridade e organização arquitetural inspirada no padrão MVC, além de persistência de dados em arquivos `.txt`.

O projeto também resultou na submissão de um artigo científico ao ERI-ES, atualmente em processo de avaliação.

**Tecnologias:** Java, JavaFX, Maven e Estruturas de Dados.

### 🌱 [Sistema de Irrigação Inteligente](https://github.com/Nuillexe/sempre-verde-project)

Projeto de iniciação científica desenvolvido durante o ensino médio, com a proposta de criar um sistema automatizado e inteligente de irrigação para uma horta. A solução buscava identificar os momentos mais adequados para realizar a irrigação, contribuindo para o desenvolvimento das plantas e para o uso eficiente da água, reduzindo desperdícios.

O projeto foi submetido à **FEBRACE (Feira Brasileira de Ciências e Engenharia)**, sendo selecionado como semifinalista da edição de 2023.

**Área:** Robótica, automação e sustentabilidade.

### 💻 [Minicurso de JavaFX – WeekIT](https://github.com/Nuillexe/minicurso-javafx)

Material didático desenvolvido para o minicurso **"Introdução ao JavaFX: Construindo uma Interface de Cadastro de Clientes"**, ministrado durante o evento WeekIT. O conteúdo aborda os fundamentos do JavaFX, a construção de interfaces gráficas e a utilização do Scene Builder no desenvolvimento de uma aplicação prática de cadastro de clientes.

**Tecnologias:** Java, JavaFX e Scene Builder.
